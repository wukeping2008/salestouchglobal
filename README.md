# LongArena (SalesTouch Overseas)

LongArena (SalesTouch Overseas) is a cutting-edge AI-powered platform designed for sales experts, consultants, and master coaches to scale their expertise and empower their sales teams globally.

## 🚀 Key Features

- **SalesTouch (AI Sales Coach)**: An interactive AI simulator that provides expert-level feedback and coaching, helping sales professionals master conversation logic like SPIN and FAB.
- **SalesNail (Smart Page)**: A high-efficiency AI tool that generates professional sales scripts and marketing landing pages in seconds from simple notes.
- **Global Reach**: Fully localized for international markets with support for English, Chinese, French, German, and Spanish.
- **Expert-Centric Design**: Minimalist, result-oriented interface designed to build trust and highlight professional results.

## 🏗️ Project Structure

- `frontend/`: A modern Vue.js application providing a premium, interactive landing page and demo experience.
- `backend/`: Node.js/TypeScript backend powering the AI interactions and data management.

## 🛠️ Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
# Copy .env.example to .env and configure your variables
npm run dev
```
